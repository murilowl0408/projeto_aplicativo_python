# 🍽️ Sabor Express

O **Sabor Express** é uma aplicação de linha de comando desenvolvida em **Python** para gerenciamento básico de restaurantes.

O projeto permite **cadastrar restaurantes, listar os restaurantes cadastrados e alterar o estado de funcionamento** de cada estabelecimento, utilizando estruturas de dados e conceitos fundamentais da linguagem Python.

### Funcionalidades

- Cadastro de novos restaurantes
- Listagem dos restaurantes cadastrados
- Exibição da categoria e estado de cada restaurante
- Ativação e desativação de restaurantes
- Validação de opções inválidas no menu
- Interface simples através do terminal

### Conceitos praticados

Durante o desenvolvimento, foram utilizados conceitos importantes de Python, como:

- Listas e dicionários
- Funções
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`)
- Tratamento de exceções (`try/except`)
- Manipulação de strings
- Entrada de dados com `input()`
- Organização de código em funções
- Importação e utilização de módulos

### Tecnologias

- **Python 3**
- **Terminal / CLI**
